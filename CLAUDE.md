# CLAUDE.md

iOS app (SwiftUI, iOS 17+) for learning Oxford 3000/5000 words with flip cards. UI language: Russian.

Source of truth — read before coding:
- `docs/01-product-spec.md` — behaviour, algorithms (§1.4 daily plan, §1.5 session, §1.6 Leitner), edge cases (§1.9)
- `docs/02-architecture.md` — layers, models, folder layout, design tokens
- `docs/03-data-pipeline.md` — `words.json` format and tooling
- `docs/04-roadmap-dod.md` — stages; implement in order, tick DoD checkboxes when done

Rules:
- All learning logic lives in `Packages/StudyCore` (Foundation only, no SwiftUI/SwiftData/AVFoundation) so `swift test` runs on Linux.
- Never call `Date()` / unseeded random in logic — inject `DayClock` and `SeededRandom`.
- Views never touch SwiftData directly; go through ViewModel → `StudyService`.
- `.xcodeproj` is generated by XcodeGen from `project.yml`; never edit it by hand.
- No third-party dependencies.
- Every user action is persisted immediately; undo restores exact snapshots.
- If behaviour is ambiguous, update the spec doc together with the code.

Commands:
- `cd Packages/StudyCore && swift test`
- `xcodegen && xcodebuild test -scheme EnglishCards -destination 'platform=iOS Simulator,name=iPhone 16'`
- `make data` — rebuild `App/Resources/words.json`

# Проверка на iPhone: пошаговый чек-лист

Всё, что можно проверить автоматически, проверяется в CI (тесты ядра, юнит-тесты и UI-тесты на
симуляторе, автоматический аудит доступности). Остальное — только на настоящем телефоне. Это
занимает около 20 минут, плюс три дня обычного использования.

## 0. Установка

1. Mac с Xcode 16 или новее, iPhone с iOS 17+, кабель.
2. В терминале: `brew install xcodegen`, затем в папке проекта
   `cp Config/Local.xcconfig.example Config/Local.xcconfig` и впишите свой Team ID и уникальный bundle id
   (Team ID виден в Xcode → Settings → Accounts).
3. `xcodegen` и `open EnglishCards.xcodeproj`.
4. На iPhone: Настройки → Конфиденциальность и безопасность → Режим разработчика → включить, перезагрузить.
5. В Xcode выберите свой iPhone вверху и нажмите ▶. При первом запуске: Настройки → Основные →
   VPN и управление устройством → довериться разработчику.

С бесплатным Apple ID приложение работает 7 дней, потом его нужно установить заново (прогресс при
переустановке из Xcode сохраняется, если не удалять приложение; на всякий случай делайте экспорт).

## 1. Первый запуск (5 минут)

- [ ] Запуск до первой карточки занимает 1–2 секунды (заставка в цвет фона, без белой вспышки).
- [ ] Открывается справка «?» один раз; после закрытия красная точка пропадает.
- [ ] Карточка переворачивается по тапу и по кнопке «Перевод», анимация плавная.
- [ ] Свайп вправо = «Выучил», влево = «Ещё учу»; короткий свайп возвращает карточку; на пороге есть лёгкая вибрация.
- [ ] «Ещё учу» возвращает слово примерно через 7 карточек; ↶ отменяет последнее действие.
- [ ] Значок динамика читает слово; в беззвучном режиме звук всё равно есть.
- [ ] Переключатель EN-RU / RU-EN меняет стороны, выбор сохраняется после перезапуска приложения.

## 2. Вид (5 минут)

- [ ] Светлая и тёмная тема (Настройки → Оформление): везде читаемо, нет белых пятен.
- [ ] Настройки → Экран и яркость → Размер текста: максимальный, и «Универсальный доступ → Дисплей и размер
      текста → Увеличенный текст» на максимум: экраны прокручиваются, кнопки «Выучил» и «Ещё учу» доступны.
- [ ] Универсальный доступ → Движение → Уменьшение движения: карточка меняется без 3D-поворота.
- [ ] VoiceOver (тройное нажатие боковой кнопки): у карточки есть действия «Выучил», «Ещё учу», «Уже знаю», «Озвучить».

## 3. Уведомления (2 минуты + 1 день)

- [ ] Закончите набор на день: приложение спросит разрешение на уведомления (не раньше).
- [ ] Настройки → Напоминание: поставьте время через 2–3 минуты, выйдите из приложения — придёт уведомление
      «Сегодня ещё N новых слов и M повторений».
- [ ] Если набор и повторения за сегодня пройдены, на сегодня уведомление не приходит.

## 4. Три дня (главная приёмка)

- День 1: выучите 60 слов, часть отметьте «Ещё учу».
- День 2: «ещё учу» пришли в начале набора, выученные вчера — во вкладке «Повторить», бейдж на вкладке совпадает с числом.
- День 3: слова, которые вы «забыли» во вкладке «Повторить», вернулись в набор.
- [ ] Серия на вкладке «Прогресс» растёт; график показывает выученное по дням.
- [ ] Настройки → Экспортировать прогресс → сохраните файл в «Файлы»; импорт этого файла возвращает то же состояние.
- [ ] За три дня приложение ни разу не вылетело.

Если что-то не работает, запишите экран и что вы нажимали — этого достаточно, чтобы воспроизвести.

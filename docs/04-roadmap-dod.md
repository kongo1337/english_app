# 4. Пошаговый план и критерии готовности

Каждый этап заканчивается рабочим состоянием и отдельным коммитом (или PR). Этап считается
закрытым только тогда, когда выполнены **все** пункты его DoD (Definition of Done).

**Общий DoD для любого этапа:**
- проект собирается без предупреждений Swift 6 strict concurrency;
- `swift test` в `Packages/StudyCore` и `xcodebuild test` проходят;
- CI зелёный;
- нет `Date()` и случайности без зерна в логике;
- нет `print` и закомментированного кода;
- новые строки интерфейса лежат в `Localizable.xcstrings`.

## Этап 2. Ядро логики (StudyCore)

**Шаги**
1. `DayKey`, `DayClock` (час начала дня, часовой пояс, `startOfNextDay`).
2. `WordProgress`, `WordStatus`, `DailyPlan`, `ReviewLogEntry`.
3. `StudyOrder` (три режима, `SeededRandom` — например SplitMix64).
4. `DailyPlanBuilder` по формуле §1.4.
5. `LearnSessionQueue`: `learned`, `stillLearning` (вставка через 7), `known`, `undo`, признак «круг пройден», `addExtra(10)`.
6. `LeitnerScheduler` и `ReviewQueueBuilder`.
7. `StatsCalculator`: серия, итоги, данные по дням, по уровням, прогноз на 7 дней.
8. Протокол `ProgressRepository` и `InMemoryProgressRepository`.

**DoD — каждый сценарий покрыт тестом:**
- [ ] Первая установка, N=60 → в наборе 60 слов `new` в порядке изучения, хвост пуст.
- [ ] Хвост 5 → набор 65, хвост идёт первым, самые давние раньше.
- [ ] Хвост 30, B=20 → 30 + 50. Хвост 100 → 100 + 0.
- [ ] Повторный `ensureToday` в тот же `dayKey` возвращает тот же план, без пересборки.
- [ ] 03:59 относится к предыдущему учебному дню, 04:00 — к новому (при dayStartHour = 4); при смене часового пояса `dayKey` пересчитывается корректно.
- [ ] Слова `known`, `review`, `mastered` никогда не попадают в новые; выключенный словарь не даёт новых слов.
- [ ] Словари закончились → только хвост; всё пусто → состояние `allDone`.
- [ ] «Ещё учу» вставляет слово на позицию 7 (или в конец); «Выучил» убирает из очереди и даёт `review`, коробку 1, срок завтра.
- [ ] После того как все слова показаны хотя бы раз и остались только «ещё учу», `isRoundComplete == true`.
- [ ] Отмена (до 10 шагов) возвращает побайтно равные `WordProgress` и `DailyPlan`.
- [ ] «Помню» проходит интервалы 1, 3, 7, 14, 30, 60; «Помню» в коробке 6 → `mastered`.
- [ ] «Забыл» → `learning`, коробка 0, `lapses + 1`; слово появляется в хвосте завтрашнего плана.
- [ ] Очередь повторений: все `due ≤ today`, сначала самые просроченные, лимит соблюдается.
- [ ] Серия: день засчитывается при ≥ 80 % набора или всех пройденных повторениях; пропуск дня обнуляет серию.
- [ ] Порядок с одинаковым зерном одинаков между запусками.
- [ ] Покрытие StudyCore строками ≥ 90 %.

## Этап 3. Хранение и сервисы

**Шаги**
1. SwiftData-модели, `VersionedSchema` v1, `SwiftDataProgressRepository` (маппинг в value types StudyCore).
2. `SettingsStore` (все настройки из §1.7.6 с умолчаниями).
3. `StudyService` (`@MainActor @Observable`): `ensureToday`, `apply(action)`, стек отмены,
   `reviewDueCount`, проверка смены дня по `scenePhase` и по таймеру на `startOfNextDay`.
4. `SpeechService` (выбор голоса en-GB/en-US, скорость, остановка предыдущей фразы).
5. `HapticsService`.
6. `AppContainer` собирает зависимости; для превью и UI-тестов — режим in-memory с фиксированной датой
   (аргумент запуска `-uiTesting`).

**DoD**
- [ ] Те же сценарии этапа 2 проходят через `StudyService` и `SwiftDataProgressRepository` (тесты в `AppTests` с in-memory контейнером).
- [ ] Принудительная остановка приложения после любого действия → после перезапуска состояние то же (тест: сохранение → новый контейнер → чтение).
- [ ] Смена дня при открытом приложении создаёт новый план не позже чем через 1 секунду после наступления границы дня или возврата в приложение.
- [ ] Озвучка работает в беззвучном режиме (`AVAudioSession` категории `.playback`), голос соответствует настройке.

## Этап 4. Экран «Учить» (главный)

**Шаги**
1. `FlashCardView`: лицевая и обратная стороны, 3D-переворот, Reduce Motion, стопка из 2 карточек.
2. Шапка: заголовок, «Выучено X из Y за сегодня», прогресс-бар, RU-EN, ?, ↶.
3. Кнопки «Ещё учу» / «Выучил», свайпы с порогом и подсказкой, haptics.
4. Меню «⋯»: «Уже знаю», «★ В избранное».
5. Лист «Круг пройден», экран «На сегодня всё» с таймером, «Ещё 10 слов», «Повторить · N».
6. Пустое состояние «Все слова пройдены».
7. Справка «?» (автоматически при первом запуске, красная точка до открытия).

**DoD**
- [ ] Визуально соответствует референсу: фон, шрифты с засечками в заголовках, капсулы, скругления, тени (сравнение скриншотов в светлой и тёмной теме).
- [ ] Тап по карточке и кнопка «Перевод» переворачивают карточку за ≤ 0.5 с без рывков (60 fps на iPhone 12 и новее).
- [ ] Свайп меньше порога возвращает карточку; больше порога — то же действие, что и кнопка.
- [ ] Счётчик «X из Y» и прогресс-бар меняются сразу после действия.
- [ ] Отмена возвращает предыдущую карточку и её состояние.
- [ ] RU-EN меняет стороны местами, выбор сохраняется.
- [ ] Таймер на экране завершения считает до начала следующего учебного дня; когда доходит до нуля, автоматически появляется новый набор.
- [ ] VoiceOver: все действия доступны без жестов.
- [ ] UI-тест: пройти 3 карточки («Выучил», «Ещё учу», «Выучил») → счётчик «2 из 60», карточка «ещё учу» появляется снова через 7 карточек.

## Этап 7. Прогресс и настройки

**Шаги**
1. `ProgressView`: серия, итоги, графики Swift Charts, по уровням и словарям, прогноз.
2. `SettingsView`: все настройки из §1.7.6.
3. `NotificationService`: разрешение после первой сессии, перепланирование на 7 дней вперёд.
4. `BackupService`: экспорт и импорт JSON, сброс прогресса.

**DoD**
- [ ] Цифры на «Прогресс» совпадают с `StatsCalculator` на тестовых данных (снимок за 30 дней).
- [ ] Изменение N действует с завтрашнего дня; изменение часа начала дня немедленно пересчитывает таймер.
- [ ] Уведомление приходит в заданное время, если план не выполнен, и не приходит, если выполнен (ручная проверка на устройстве и юнит-тест планировщика).
- [ ] Цикл «экспорт → сброс → импорт» восстанавливает идентичное состояние (тест).
- [ ] Сброс прогресса требует двойного подтверждения.

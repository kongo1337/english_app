# English Cards — iPhone-приложение для изучения слов Oxford 3000 / 5000

Личное iOS-приложение с карточками: на лицевой стороне английское слово, по кнопке «Перевод»
(или тапу) карточка переворачивается и показывает перевод на русский. Каждый день формируется
набор из ~60 слов, под карточкой две кнопки — **«Выучил»** и **«Ещё учу»**. Слова «ещё учу»
переносятся в следующие дни, выученные уходят на интервальное повторение.

Визуальный референс: [`docs/design/reference.webp`](docs/design/reference.webp).

## Запуск на Mac

```bash
brew install xcodegen
cp Config/Local.xcconfig.example Config/Local.xcconfig   # впишите свой Team ID и уникальный bundle id
xcodegen                                                 # создаёт EnglishCards.xcodeproj (в git его нет)
open EnglishCards.xcodeproj
```

В Xcode выберите симулятор iPhone и нажмите ▶. Чтобы поставить на свой iPhone: подключите его
кабелем, включите «Режим разработчика» (Настройки → Конфиденциальность и безопасность), выберите
iPhone в списке устройств и нажмите ▶; при первом запуске доверьте профиль разработчика
(Настройки → Основные → VPN и управление устройством).

Логику без Xcode можно проверить на любой ОС со Swift 6: `cd Packages/StudyCore && swift test`.

## Ключевые решения (кратко)

- **Нативное iOS**: Swift + SwiftUI, iOS 17+, без сторонних зависимостей.
- **Офлайн**: оба словаря зашиты в приложение (`words.json`), сеть не нужна.
- **Прогресс** хранится в SwiftData, настройки в UserDefaults; резервная копия в JSON-файл.
- **Логика обучения** (дневной набор, интервальные повторения, смена дня) вынесена в Swift
  Package `StudyCore` на чистом Foundation: её можно тестировать даже без Mac (`swift test` на Linux/CI).
- **Проект генерируется XcodeGen** из `project.yml`, чтобы не править `.xcodeproj` вручную.

## Что добавлено сверх исходной идеи

1. **Интервальные повторения** (вкладка «Повторить» с бейджем): выученные слова возвращаются через 1, 3, 7, 14, 30, 60 дней. Без этого выученное за месяц забывается.
2. **Озвучка** слова и примера (системный синтез речи, американский/британский акцент), офлайн.
3. **Транскрипция, часть речи, уровень CEFR** (A1–C1) и **пример предложения** с переводом на карточке.
4. **Свайпы** вправо/влево как дубли кнопок, **отмена** последнего действия, тактильный отклик.
5. **Режим RU→EN** (переключатель как на референсе): сначала видишь русский, вспоминаешь английский.
6. **«Уже знаю»**: убрать слово навсегда, чтобы не тратить на него дневной лимит.
7. **Экран «На сегодня всё»** с таймером до нового дня и кнопками «Повторить» / «Ещё 10 слов».
8. **Прогресс**: серия дней подряд, график по дням, прогресс по уровням и словарям, прогноз повторений.
9. **Браузер словарей** с поиском и фильтрами по уровню и статусу.
10. **Напоминания** (локальные уведомления) в выбранное время, если план дня не выполнен.
11. **Настройки**: размер дневного набора, порядок слов, час смены дня, акцент озвучки, тема.
12. **Экспорт/импорт прогресса** в файл, чтобы не потерять его при смене телефона.

Платные тарифы Free/Pro и экран блокировки из референса не делаем: приложение личное. Вместо
экрана блокировки будет экран «План на сегодня выполнен» в том же стиле.

## Что понадобится для сборки

- Mac с Xcode 16 или новее (iOS-приложение собирается только на macOS).
- iPhone с iOS 17+ и Apple ID. С бесплатным Apple ID приложение ставится по кабелю и работает
  7 дней, потом его нужно переустановить. Apple Developer Program ($99 в год) снимает это
  ограничение и даёт TestFlight и синхронизацию через iCloud.
- Python 3.11+ для подготовки словарей (скрипты в `tools/`).
